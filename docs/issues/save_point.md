# 開発方針の参照点

AIは機能追加・設計変更の前にこのファイルを読み、関連する設計メモを確認すること。

## 現在の方針

- ネイティブ版を優先して作り込む。ブラウザー版の実装は、現時点の作業として要求されていない。
- 内蔵YM2612・PSGと外部音源をMIDI出力先として扱う、現在の構成を活かす。
- 将来ブラウザー版を追加できるよう、演奏コード・Workerの共通処理と、環境固有の接続・音声処理の境界を意識する。
- 機能追加時には環境依存の処理をどこに置くか確認する。ただし、将来への備えを理由に作業範囲を広げない。
