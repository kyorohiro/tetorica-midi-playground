# MIDI Playground TODO

FM2612 Playgroundとの機能差を整理する。MIDI版は基本的な演奏機能を移した段階であり、同名APIも完全互換ではない。

## 現在の対応範囲

- `play` / `beat` / `setBpm`、MIDIチャンネル・velocity指定。
- `choose` / `scale` / `cycle`。
- `liveLoop`、画面のRun / Stop。Runごとに全ループを再起動する。
- Run file選択（既定 `/index.js`）、ファイル保存・import/export。
- MIDI出力選択時の自動接続、接続先・状態の表示。
- 外部MIDI Clockの監視とC4テスト。JavaScriptの演奏は内部BPMで動作する。

## 優先1: 拍・ループの互換性

- [ ] `nextBeat()`：共通の拍の境界に合わせて待機する。基準時刻、BPM変更時の扱いを定義する。
- [ ] `stopLoop(name)` / `stopAllLoops()`：個別・全ループの停止を追加する。待機中の処理、送信済みノートのNote Off、再起動時の扱いを検証する。
- [ ] `cycle()`：FM版のループ単位・呼び出し位置単位の状態管理に合わせる。現在はRun内でカウンターを共有するため、複数ループが干渉し得る。
- [ ] `liveLoop`の更新：FM版の再評価・ループ差し替え動作を調査し、継続する状態とリセットする状態を定義する。現在はRunで全停止・再起動。
