Quick start
Connect an output in MIDI settings. In GarageBand, select a software instrument track. Choose a script in Run file and press Run. The default is /index.js, even while viewing README.md.
setBpm(120);
await play("C4", { duration: 0.5 });
await play("E4", { duration: 0.5 });
await play("G4", { duration: 1 });
  • play(note, {duration, channel, velocity}): duration in beats, channel 1–16, velocity 1–127. Waits for the note length. Native Note Off.
  • noteOn(note, {channel, velocity}) / noteOff(note, {channel, velocity}): held notes on the selected MIDI output; Stop releases tracked notes.
  • cc(controller, value, {channel}), programChange(program, {channel}), pitchBend(value, {channel}), channelPressure(value, {channel}), polyPressure(note, value, {channel}): MIDI controls. Values/programs 0–127, bend -1…1; support depends on the receiver.
  • send(bytes): one raw MIDI message; raw notes are not automatically released. See FILES guide and examples 11/12.
  • beat(count): rest for beats at the internal BPM.
  • nextBeat(): wait for the next internal beat boundary.
  • chord(root, name): chord note names (major, minor, major7, minor7, dominant7).
  • rand(), rrange(min, max), randInt(min, max), lerp(a, b, t), noteLerp(from, to, t) (nearest MIDI note; no Pitch Bend).
  • setBpm(bpm), choose(array), log(...values).
  • onKeyboardPressKey(name, callback) / onKeyboardReleaseKey(name, callback): Run, then focus Keyboard input above the editor. Callback receives key/code and modifier flags.
  • liveLoop(name, async () => {...}): repeat until Stop. Each Run restarts all loops. Use callback helpers, e.g. async ({play, beat, cycle}) => {...}, for loop-local cycles and cancellation. stopLoop(name) / stopAllLoops() stop loops and release notes sent through their scoped play helpers.
Scripts run in a terminable Worker. Use await import("./notes.js") for FILES modules; see README in FILES. No FM presets or audio effects. External Clock beat waits are experimental; see the FILES guide. Scripts are trusted local code, not a security sandbox.
Files are saved locally in this app. Export file to keep a separate backup. Keyboard focus must be outside native dialogs for shortcuts.
