MIDI Playground API

    
Use pg. to explore the API with completion, or call helpers directly: pg.play(...) and play(...). Channels are 1–16; durations and waits are in beats. Top-level await is available.

    
Choose the script in Run file, then Run. Viewing a file does not change the Run file. Detailed English/Japanese guides and runnable examples are in FILES.

    
First sound — no external MIDI setup

    
await enableSoundChip("ym2612");
const piano = midi.output("tetorica-ym2612", { channel: 1 });
await piano.play("C4", { duration: 0.5, velocity: 90 });

  

  

    

      
Outputs & notes

      
    
        
  • await enableSoundChip("ym2612")Enable the native sound rack. Also accepts "sega-psg"; repeated calls preserve rack settings.
    • 
        
  • const piano = midi.output("tetorica-ym2612", { channel: 1 })Create a destination handle. Use "tetorica-sega-psg" for PSG, or an external port's unique name. Connection opens on first play or voice transfer.
    • 
        
  • await piano.setVoice(preset)YM2612: use an FM2612 Preset Object, or binary data with {format: "tfi"} / {format: "vgi"}. Changes the next note; held notes keep their voice. Omit channel when creating the handle to set all 16 channel voices.
    • 
        
  • await piano.loadVoice("./bell.tfi")Import a TFI/VGI using FILES → Import. Relative paths start at the Run file, including calls inside imported modules. Binary voices are included in project exports. See examples/13_ym2612_voice.js.
    • 
        
  • midi.output(MIDI_OUTPUT_01, { channel: 2 })Use an assignment from MIDI connections. Available slots: MIDI_OUTPUT_01, MIDI_OUTPUT_02, MIDI_OUTPUT_03, MIDI_OUTPUT_04. Assign them before use.
    • 
        
  • await piano.play("C4", { duration: 0.5, velocity: 90 })Play on the handle's channel. A note can be a name such as "Bb3" or MIDI number 0–127. Duration defaults to 0.5 beats; velocity to 90.
    • 
        
  • await play("C4", { channel: 1, duration: 0.5, velocity: 90 })Use the MIDI output selected in the UI. Velocity is 1–127. await waits for the duration; omitting it allows overlapping notes.
    • 
        
  • await ctx.playOutput(piano, "C4", { duration: 0.5 })Keep a handle's notes owned by a loop when passing its helpers to imported functions. Also available as playOutput(...).
    • 
      

    

    

      
Low-level MIDI

      
These use the selected MIDI output, not a midi.output() handle. They return a Promise for sending, not for note duration. Default channel: 1.

      
    
        
  • await noteOn("C4", { channel: 1, velocity: 100 })Hold a note until noteOff or cleanup. Velocity: 1–127, default 90.
    • 
        
  • await noteOff("C4", { channel: 1, velocity: 0 })Release a note. Release velocity: 0–127, default 0.
    • 
        
  • await cc(1, 64, { channel: 1 })Control Change. Controller and value: integers 0–127. Common controls: 1 modulation, 7 volume, 10 pan, 11 expression, 64 sustain.
    • 
        
  • await programChange(30, { channel: 1 })Raw program number 0–127. Internal preset-number mapping is pending; use the YM2612 tab to edit its channel patch.
    • 
        
  • await pitchBend(0.5, { channel: 1 })-1 minimum, 0 center, +1 maximum. Internal range: ±2 semitones. External range depends on the receiver.
    • 
        
  • await channelPressure(80, { channel: 1 })Channel aftertouch, integer 0–127.
    • 
        
  • await polyPressure("C4", 80, { channel: 1 })Per-note aftertouch, integer 0–127.
    • 
        
  • await send(new Uint8Array([0xB0, 1, 64]))Send one complete raw MIDI message; a regular Array also works. System messages and framed SysEx are supported by the transport. Raw notes/pedals are not tracked: send their release messages yourself.
    • 
      

      
Try examples/11_midi_pitch_bend.js and examples/12_midi_cc.js.

    

    

      
Timing & live loops

      
    
        
  • setBpm(120)Set the internal tempo.
    • 
        
  • await beat(0.5)Wait half a beat. Default: 1 beat.
    • 
        
  • await nextBeat()Wait for the next beat boundary.
    • 
        
  • liveLoop("lead", async ctx => { ... })Create or replace a named repeating loop. Use ctx.play(), ctx.noteOn(), ctx.beat() or ctx.pg to keep timing and cancellation local.
    • 
        
  • stopLoop("lead")Stop one loop and release its tracked notes.
    • 
        
  • stopAllLoops()Stop all named loops. The Stop button stops the whole Run.
    • 
      

      
liveLoop("lead", async ({ play, beat, cycle }) => {
  await play(cycle(["C4", "E4", "G4"]), { duration: 0.25 });
  await beat(0.25);
});

      
Direct parameterless inline block callbacks also bind loop-local helpers automatically. Apply replaces same-name loops and keeps the clock; other loops continue. Run restarts everything. External MIDI Clock is experimental; see the guide.

    

    

      
Scales, chords & patterns

      
    
        
  • scale("E4", "minorPentatonic", 2)Return note names over 2 octaves (default 1). Scales: major, minor, majorPentatonic, minorPentatonic.
    • 
        
  • chord("C4", "major7")Return note names. Chords: major, minor, major7, minor7, dominant7. Does not play them automatically.
    • 
        
  • choose(["C4", "E4", "G4"])Choose a random element from a nonempty array.
    • 
        
  • cycle(["C4", "E4", "G4"])Return successive elements; loop-local counters restart when that loop is replaced.
    • 
        
  • cycle("bass", ["C3", "G3"])Use a named cycle counter.
    • 
        
  • rand()Random number from 0 inclusive to 1 exclusive.
    • 
        
  • rrange(0.2, 0.8)Random number between the supplied bounds.
    • 
        
  • randInt(60, 72)Random integer; both endpoints included.
    • 
        
  • lerp(0, 100, 0.5)Linear interpolation; this example returns 50.
    • 
        
  • noteLerp("C4", "C5", 0.5)Interpolate and round to a MIDI note number. This does not send Pitch Bend.
    • 
      

    

    

      
pg.context & JSDoc

      
context and pg.context are the same shared state object. Apply preserves it; Run creates a new one. It is not saved in project cassettes.

      
/** @typedef {{ count?: number }} State */
const state = /** @type {State} */ (pg.context);
state.count = (state.count ?? 0) + 1;
log("Evaluation count:", state.count);

      
JSDoc provides completion and hover. Types include MidiOutput, MidiNote, MidiPlayOptions and TetoricaContext.

      
A liveLoop callback parameter named context is the loop's helper API, distinct from global shared state. Its context.context property accesses shared state.

      
Try examples/10_context_init.js for retained initialization, or examples/03_context_jsdoc.js for typed loop helpers.

    

    

      
Files, imports & Console

      
    
        
  • const p = await import("./lib/phrase.js")Import a FILES module relative to the current file. Include .js or .mjs. The editor completes paths and exported members.
    • 
        
  • log("note", 60)Write to Console. console.log(), console.warn() and console.error() also write there.
    • 
      

      
Imported functions do not inherit the Run file's helpers: pass the loop API and output handle as arguments. Run files use dynamic import; imported modules may use static relative imports/exports. npm packages and remote URLs are not supported.

      
Script errors stop the Run and notify you in the status bar without switching tabs. Open Console for details.

      
Menu → Export project saves files and playback settings as my-project.midi.cassette.zip. Import project restores them; New Project starts with the default lead loop. Export file saves only the viewed file.

    

    

      
Keyboard callbacks

      
    
        
  • onKeyboardPressKey("notes", async event => { ... })Register a named key-down handler.
    • 
        
  • onKeyboardReleaseKey("notes", async event => { ... })Register a named key-up handler. Reusing a name replaces that handler.
    • 
      

      
onKeyboardPressKey("notes", async event => {
  if (event.code === "KeyA") await noteOn("C4");
});
onKeyboardReleaseKey("notes", async event => {
  if (event.code === "KeyA") await noteOff("C4");
});

      
Select a MIDI output, Run, then focus Keyboard input above the editor. Typing in the editor does not play notes. Events include key, code, repeat and modifier flags; they are not DOM events. Stop releases tracked notes.

    

    

      
Internal YM2612 / Sega PSG

      
For selected-output helpers such as noteOn(), choose Tetorica YM2612 or Tetorica Sega PSG in MIDI connections. Selecting an internal output enables it automatically.

      
    
        
  • Pitch Bend±2 semitones on tonal voices. PSG CH10 is fixed-pitch noise.
    • 
        
  • CC7 / CC11 / CC10Channel volume / expression / pan. YM2612 pan is left/center/right; PSG uses software stereo pan.
    • 
        
  • CC64 / CC66Sustain / sostenuto. Tracked pedals are released on Stop or owner-loop cleanup.
    • 
        
  • CC1 / channelPressure / polyPressure5 Hz vibrato, up to ±0.5 semitone. The largest value determines depth.
    • 
        
  • CC120 / CC123 / CC121All Sound Off / All Notes Off (obeys pedals) / Reset Controllers (preserves volume and pan).
    • 
      

      
Program Change preset mapping and internal SysEx handling are pending. Edit FM patches in the YM2612 tab; adjust source levels in Mixer. Direct fm/fx APIs from the original Playground are not exposed here.
